# Sphere Grid

A reusable 3D learning skill tree. Polar map, Final Fantasy X board language, modern materials.

**Radius is distance from a first principle. Angle is which principle you descend from. A node opens once everything inward of it on its ray is derived.**

This is a game that is not a game: a cinematic disc you walk with a cursor, not a worksheet.

## What it is

- Full-bleed Three.js sphere grid (React Three Fiber)
- Carved-stone calendar disc, crystal gems, dashed corridors, bloom
- Three curricula: **Method**, **Machine learning**, **Physics**, with bridges between them
- Progress persisted on-device
- Data-driven graphs so you can drop in another subject

## Stack

TanStack Start · React 19 · Three.js · @react-three/fiber · drei · postprocessing · Zustand · Tailwind v4

## Recreate it

The prompt that produced this app (without chat history) lives in [`PROMPT.md`](./PROMPT.md). Paste that into an app builder that can ship a Three.js product.

## Local

```bash
npm install
npm run dev
```

Tap **Method**, derive it, work the rings out. `1` / `2` / `3` switch domains. Enter derives the open node.
